# votes-es v0.2.0 — release notes

Candidate: `votes-es:0.2.0-rc1` · dataset `20261007T171732Z` · schema 2.

## What changed

- **Canonical proposal model v2.** Three additive artifacts —
  `official_agenda_items` (435 items, 26 meetings, per-row provenance),
  `canonical_proposals` (5,369), `proposal_anchor_links` (many-to-many
  bridge: SAME 5,348 · AMBIGUOUS 76 · UNMATCHED 7 · BUNDLES 8 · NOISE 4).
- **Official-agenda anchoring.** Identity for covered meetings comes
  from convocatoria evidence (BORME 13 · CNMV 2 · issuer 11), not
  reporter wording.
- **Bundle-safe mapping.** One source vote over a bundle stays a
  bundle-level fact; it is never fanned out to sub-items. Comparable
  views include only `SAME`/`SUBITEM_OF`.
- **Additive API.** `GET /api/v1/meetings/{id}/agenda` and
  `GET /api/v1/compare/canonical` (shared proposals / observations /
  units with explicit excluded-by-reason coverage).
- **Rights gate.** Agenda titles published verbatim only for
  BORME-sourced items with AEBOE attribution; CNMV pending review;
  issuer-site served metadata-only (item number + factual label +
  source link). See `docs/legal/OFFICIAL-AGENDA-REUSE.md` and
  `docs/legal/NORMALIZED-FACTS-POLICY.md`.
- **Information-only gate.** Filers reporting dispositions on
  officially information-only items (Inditex item 10, CaixaBank 8.1)
  are preserved as anomalies and excluded from comparisons — QA check
  `information_only_with_reported_vote` (WARN).
- **Stable v0.1 IDs.** `proposal_id`, `vote_id`, `meeting_id`
  untouched; 165,725 public votes identical.

## What did not change

- Public votes remain **SEC N-PX only** (`sec_npx`; 165,725 rows,
  261 meetings, 130 issuers).
- MAPFRE remains gated — reclassified `NORMALIZED_FACTS_ALLOWED` in the
  registry (facts-only model) but still OFF: enabling is an explicit
  `VOTES_PUBLISH_VOTE_SOURCES` decision, not a side-effect.
- ISS VDS remains blocked (`PROHIBITED_BY_TERMS`).
- No `/api/v2`; no endpoint changed semantics (ADR-002).

## Coverage disclosure

Official agendas cover **26 of 261 meetings**. Canonical identity is
graded: `OFFICIAL_AGENDA` 420 · `SOURCE_CONSENSUS` 4,862 (fallback —
not equivalent epistemologically) · `UNRESOLVED` 87 (kept visible, never
forced). N-PX public meetings without agenda remain consensus-based.

## Rollback procedure

Dataset generations are atomic under `dist/generations/<id>` +
`dist/CURRENT`; the image mounts `<gen>/gold/votes.duckdb`.

```text
forward:  build gen (scripts/release.py) → point CURRENT → redeploy image
rollback: repoint CURRENT to the prior schema-1 generation AND redeploy
          the matching v0.1 image — v0.2 code expects the canonical
          tables, so image+dataset must roll together
```

Schema-1 gold opens fine under the v0.2 code only when the canonical
tables exist; keep pairs (image, generation) versioned together.
