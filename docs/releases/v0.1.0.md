## Semantics in this release

- N-PX `managementRecommendation` is the **alignment** flag; UI shows
  "Relative to management". Dissent on N-PX = alignment AGAINST.
- Restatements supersede; `NEW PROXY` amendments add. No latest-wins.
- Split components preserved; SPLIT shown with per-lot breakdown on the
  vote-explain view.
- `·` in the matrix = not observed / not disclosed — never "did not vote".

## Known limitations

- OpenInstrument carries no CUSIP lane → CUSIP-only rows unresolved by
  design; 10 issuer rows remain UNRESOLVED (warnings, not hidden).
- VDS vote rows withheld pending reuse review; VDS metadata/links remain.
- Season not frozen-complete: late filings/amendments during open 2026-Q4
  land via incremental refresh runs.

## Deployment

Coolify-proxy (Traefik) routed container on the `coolify` Docker network,
TLS via Let's Encrypt. Generations at `/data/votes-es/generations/<id>/`,
`CURRENT` symlink switch is atomic and per-request (DuckDB re-opened per
query). Rollback = `mv -T` the symlink back. CURRENT+PREVIOUS retained.
